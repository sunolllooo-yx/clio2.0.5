## 这是什么
## What This Is

Clio 是一个个人专属的灵感记录工具，完全离线，数据只存在你自己的电脑上。
Clio is a personal inspiration-recording tool. It's fully offline, and your data lives only on your own computer.

没有账号、没有登录、没有云端、没有社交功能。
No account, no login, no cloud, no social features.

## 主要功能
## Main Features

### 灵感（发帖）
### Inspiration (Posting)

- 一条帖子 = 文字 + 红 tag（≥1）+ 蓝 tag（≥1）+ 可选媒体
- One post = text + red tags (≥1) + blue tags (≥1) + optional media

- 灵感分「内容」和「来源」两套 tag 体系，用来归纳整理
- Inspiration is organized with two tag systems: "content" and "source"

- 支持在编辑时删除、修改已加的 tag
- You can delete or edit tags that have already been added

- 信息流按时间倒序，支持编辑、删除、查看修改记录
- The feed is in reverse-chronological order, with edit, delete and revision history

### 多媒体【2.0 新增】
### Media [New in 2.0]

- **图片**：单图 / 多图，按张数自动排版（大图 / 宫格 / 轮播），可全屏浏览、缩放、左右切换
- **Images**: single or multiple; layout adapts to the count (large image / grid / carousel); full-screen viewing with zoom and left/right switching

- **视频**：带封面和播放器（播放、进度、音量、倍速、全屏、画中画），只做播放
- **Videos**: cover image and player (play, progress, volume, speed, fullscreen, picture-in-picture); playback only

- **音频**：音频条播放，多个音频可顺序播放
- **Audio**: audio bar playback; multiple tracks can play in sequence

- **漫画**：封面支持纯色 / 渐变 / 自定义图片 / 预设四种方式；每次发帖即为一个章节
- **Comics**: covers can be solid color, gradient, custom image or preset; each post becomes one chapter

- **图堆**：PureRef 式的无限画布，自由摆放参考图，可拖动、缩放、平移，发帖时可引用
- **Image boards**: a PureRef-style infinite canvas for arranging reference images freely — drag, zoom, pan; can be referenced in posts

### 新手教程与语言切换【2.0 新增】
### Onboarding Tutorial & Language Switching [New in 2.0]

- **新手教程弹窗**：第一次打开软件时会弹出引导，带你认识各个模块怎么用，上手更快
- **Onboarding tutorial pop-up**: on first launch, a guided pop-up walks you through each module so you can get started faster

- **语言切换**：界面支持中英文切换，跟着自己的习惯来
- **Language switching**: the interface can be switched between Chinese and English, whichever you prefer

### 漫画阅读器
### Comic Reader

独立弹出窗口，支持：
A separate pop-up window, supporting:

- 竖屏条漫（连续滚动）
- Vertical webtoon mode (continuous scrolling)

- 横屏翻页（一屏一页，可开关翻页动画）
- Horizontal page-flip mode (one page per screen, with an optional flip animation)

- 窗口缩放时内容等比不变形
- Content scales proportionally without distortion when the window is resized

- 亮度调节、章节目录跳转
- Brightness adjustment and chapter/table-of-contents navigation

### 日记
### Diary

- 按日期记录，支持心情、天气、日历
- Records by date, with mood, weather and calendar

- 图片有两种排版：图文上下式、公众号式（图片插入段落之间）
- Two image layouts: text-then-images, or WeChat-article style with images inserted between paragraphs

- 不支持音频
- Audio is not supported

### 检索与 AI 助手
### Search & AI Assistant

- 本地全文检索，覆盖帖子、图片备注、视频标题、漫画标题 / 简介、图堆、音频名称
- Local full-text search covering posts, image notes, video titles, comic titles/synopses, image boards and audio names

- 本地 AI 做抽取式总结，不联网，结果会标注媒体类型和来源
- Local AI performs extractive summarization, without internet; results are labeled with media type and source

### 分类栏
### Category Panel

- 红 / 蓝 tag 树管理，点击节点查看相关帖子，含来源统计
- Manage red/blue tag trees, click a node to see related posts, with source statistics

### 数据与设置
### Data & Settings

- 备份 / 恢复 data.json
- Back up / restore data.json

- 完整备份（zip，含全部媒体文件）
- Full backup (zip, including all media files)

- 媒体、图堆、漫画的集中管理
- Centralized management of media, image boards and comics

## 技术特点
## Technical Highlights

- **纯本地运行**：结构化数据存在 `data.json`，媒体文件放在 `media/` 目录
- **Fully local**: structured data in `data.json`, media files under `media/`

- **低内存占用**：虚拟滚动、懒加载、缩略图、单播放器、及时释放资源
- **Low memory usage**: virtual scrolling, lazy loading, thumbnails, a single player, and timely resource release

- **完全离线**：没有 API Key、没有云端、没有外部大模型
- **Completely offline**: no API key, no cloud, no external large models

## 使用方式
## How to Use

1. 把整个 `clio2.0` 文件夹拷贝到 Windows 电脑上
1. Copy the entire `clio2.0` folder onto a Windows computer

2. 双击启动器运行（无需网络）
2. Double-click the launcher to run it (no internet needed)

3. 在浏览器中打开本地服务，开始使用
3. Open the local service in your browser and start using it

4. 第一次打开会弹出新手教程，跟着走一遍就能上手；界面语言也可以随时切换
4. A beginner tutorial pops up on first launch — just follow it to get going; you can switch the interface language at any time

> 数据保存在本机项目文件夹中，换电脑时请使用「完整备份（zip）」把媒体一起带走。
> Data is saved in the local project folder. When switching computers, use "Full backup (zip)" to bring your media along.

## 不做什么
## What It Deliberately Doesn't Do

为了保持轻量和纯粹，以下功能刻意不做：
To stay lightweight and focused, the following are deliberately excluded:

- 点赞、评论、转发、弹幕、投币、关注、推荐流
- Likes, comments, reposts, danmaku, tips, follows, recommendation feeds

- 联网搜索、云同步、在线大模型
- Online search, cloud sync, online large models

- 视频 / 音频剪辑、转码、特效
- Video/audio editing, transcoding, effects

- 图堆多人协作、AI 自动抠图排版
- Multi-user image board collaboration, AI auto cut-out and layout

- 手机端、数据加密、富文本高级排版
- Mobile clients, data encryption, advanced rich-text formatting
